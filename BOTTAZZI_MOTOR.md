# Bot-tazzi Motor

**Bot-tazzi Motor** is the low-VRAM CUDA / NVMe experimental branch in this repository.

It is built on **DwarfStar / DS4 by Salvatore "antirez" Sanfilippo**. The original project is the foundation of this work and deserves the primary credit for the inference engine and architecture.

See [`docs/BOTTAZZI_MOTOR.md`](docs/BOTTAZZI_MOTOR.md) for architecture, exact benchmark results, expert-pack generation, stable runtime settings, and rejected experiments.
